# MindForge

**Capture ideas. Connect thoughts. Organize knowledge.**

MindForge is a customizable note-taking and knowledge organization application for Windows and Android.

Designed to help you keep notes, visualize ideas, and build connections between information in one workspace.

## Features

- **Rich Notes** — Create, edit, format, and organize your notes.
- **Mind Maps** — Explore ideas through interactive visual diagrams.
- **Mind Pins** — Connect information across notes, collections, links, and mind maps.
- **Collections & Tags** — Keep your workspace structured and searchable.
- **Personalization** — Customize themes, colors, fonts, and layouts.
- **Offline Access** — Work with your local data without a constant internet connection.
- **Optional Cloud Sync** — Synchronize supported data between devices.
- **Export & Backup** — Export your work and create backups of your data.

## Installation

### Windows

Download the latest Windows installer from the Releases page and follow the installation instructions.

### Android

Download the Android APK when provided with a release. Updates must be installed using a package signed with the same signing key.

## Updates

This repository hosts official release packages and update metadata for MindForge.

Update availability and installation methods may differ between Windows and Android.

## Data & Backups

MindForge supports local data storage and backup exports. We recommend keeping a backup of important notes before major updates.
